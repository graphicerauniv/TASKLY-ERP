# Admin Finance Icon Set

This is an admin-only, transparent PNG icon family for the ERP Finance workspace. It deliberately uses a precise enterprise visual language—navy, steel, azure, cyan, and restrained gold—rather than the student portal theme.

## Assets

- `accounts-payments.png`
- `fee-books.png`
- `fee-heads.png`
- `course-fees.png`
- `hostel-fees.png`
- `scholarships.png`
- `admin-finance-icon-sprite.png` (source sheet)

Use the individual 256 × 256 files in product UI. The sprite is retained as the source sheet for consistent future derivatives.

## Generation direction

Built-in image generation was prompted to create an original enterprise admin set with sharp semi-isometric construction, machined metal, frosted glass and technical surfaces, transparent backgrounds, controlled depth, and no text, logos, student styling, clay rendering, or cartoon treatment.
